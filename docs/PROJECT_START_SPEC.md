# 357NETWORK — Project Start Specification

## Project Name
357NETWORK

## Tagline
Building Careers. Strengthening Brotherhood.

## Core Idea
357NETWORK is a job and professional opportunity network designed for Freemasons, Masonic-friendly employers, and job seekers. The first version will launch in the United States only and support English and Spanish.

## Initial Positioning
A professional employment network where Masons and Masonic-friendly employers can connect for jobs, remote work, skilled trades, business opportunities, and Traveling Man opportunities.

## Phase 1 Geographic Scope
United States only.

## Phase 1 Languages
- English
- Spanish

## Primary Users
1. Job Seekers
2. Employers
3. Advertisers
4. Admin

## Mason in Good Standing Self-Attestation
Job seekers and employers may check a box stating:

"I affirm that I am a Mason in Good Standing."

This is self-attestation only in Phase 1. The site should display this as:

Self-Attested Mason

Employers may independently verify the applicant later. Do not build Grand Lodge verification in Phase 1.

## Required Phase 1 Sections
- Home
- Find Jobs
- Post a Job
- Traveling Man Jobs
- Advertising
- Sign In / Register
- Employer Dashboard
- Job Seeker Dashboard
- Admin Review Area

## Design Direction
Professional, simple, dark theme with gold accents. No elaborate animation. No complex artwork required. Logo/header should use the 357NETWORK name and tagline.

## Payment Model
Stripe will be used for:
- Paid job listings
- Featured listings
- Advertising placements

## Deployment
Netlify.

## Backend
Supabase:
- Auth
- Database
- Row Level Security
- Storage later if resumes are added as uploads

## Do Not Build Yet
Phase 2 items are locked and should not be deployed until Phase 1 is complete and approved.
